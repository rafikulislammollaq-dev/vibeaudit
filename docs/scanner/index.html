What this checks

🔑

Leaked secrets

Live Stripe keys, Supabase service-role tokens, AWS keys, Slack and Discord webhooks, private keys and hard-coded assignments to anything named SECRET, TOKEN, PASSWORD or API_KEY. Values are redacted - the report never shows a working key.

🔒

Unprotected database tables

Postgres tables created without Row Level Security, permissive USING (true) policies, and SECURITY DEFINER functions with no pinned search_path.

🗆

Weak token handling

JWT verification that accepts alg: "none", tokens that are decoded instead of verified, and signing secrets that fall back to a hard-coded default.

🌐

CORS and debug routes

Wildcard CORS combined with credentials, reflected origins, leftover /api/debug style routes and source maps published with the build.

What it cannot do

A tool that runs in your browser stops where your folder stops. The report is explicit about the gaps: it never tests your live site, never runs a dependency audit, and cannot read your git history. The full paid review covers all of those.
